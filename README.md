# AuraStore — Modern Animated E-Commerce Angular Web Application

A full-featured, futuristic, and high-performance e-commerce platform built with Angular, rich CSS3 animations, and reactive state management.

## 🚀 Key Features

- **Fluid Modern Aesthetics**: Deep dark & frosted glassmorphism interface with neon gradient accents.
- **Dynamic Hero Banner**: Auto-sliding carousel with interactive product cards, smooth transitions, and live countdown timer.
- **Live Search & Autocomplete**: Instant search dropdown with highlight badges and product thumbnails.
- **Interactive Product Catalog**: Category filter pills, grid/list toggle, sorting (price, rating, discount).
- **Product Quick View Modal**: Multi-image thumbnail gallery, live variant selectors (colors, sizes), stock meter, and animated tabs (Description, Specifications, Reviews).
- **Slide-Out Off-Canvas Cart**: Real-time quantity adjustments, free shipping progress bar, promo code applicator (`AURA20`, `FLASH30`, `WELCOME10`), price breakdown.
- **Saved Wishlist Drawer**: One-click heart save with burst animation and move-to-cart functionality.
- **Interactive 3D Checkout**: 3-step checkout with real-time 3D credit card flip preview & celebratory confirmation receipt.
- **Toast Notification Stack**: Real-time slide-in notifications for all actions.

## 🛠️ How to Run

1. Open a terminal in `D:\ecommerce-store`
2. Run `npm install`
3. Run `npm start`
4. Open your browser at `http://localhost:4200`
